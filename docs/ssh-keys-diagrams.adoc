== Sequence: home-manager switch → SSH Ready

[mermaid]
----
sequenceDiagram
    actor User
    participant hm as home-manager
    participant Nix as ssh-keys.nix
    participant Stage1 as extract-keys.sh
    participant SOPS as SOPS Decrypt
    participant Stage2 as regenerate-certs.sh
    participant Stage3 as deploy-keys.sh
    participant RuntimeDir as ~/.local/state/ssh-keys.d/
    participant Agent as SSH Agent

    User->>hm: home-manager switch
    hm->>Nix: trigger activation
    Nix->>SOPS: decrypt nxmatic-ssh-keys.yaml
    SOPS-->>Nix: plaintext profile YAML
    Nix->>Stage1: extract keys from profile
    Stage1-->>Nix: tmp_keys_dir (keys only)
    Nix->>Stage2: regenerate certs from authorities
    Stage2-->>Nix: tmp_keys_dir (keys + certs)
    Nix->>Stage3: deploy to runtime + generate manifest
    Stage3->>RuntimeDir: rsync keys + certs + manifest
    RuntimeDir-->>Stage3: ✓ deployment complete
    Stage3-->>Nix: activation complete
    Nix->>RuntimeDir: agent-keys manifest ready
    Agent->>RuntimeDir: load from agent-keys manifest
    Agent-->>User: ✓ SSH auth ready (certs auto-loaded)
----

== Key Decision Points in Pipeline

[mermaid]
----
graph TD
    A["Extract keys?"] -->|has private field| B["✓ Extract as key pair"]
    A -->|only public/usage| C["✗ Skip (metadata only)<br/>e.g., 'host' cert authority"]
    
    B --> D["Has authorities?"]
    D -->|embedded CAs| E["✓ Regenerate certs<br/>ssh-keygen -s ca_priv"]
    D -->|no CAs| F["✓ Deploy keys only<br/>(cert-free auth)"]
    
    E --> G["Generate symlinks"]
    G --> H["<key>-cert.pub →<br/><key>-<ca>-user-cert.pub"]
    H --> I["SSH Agent auto-loads<br/>matching <key>-cert.pub"]
    
    F --> J["Deploy to runtime"]
    I --> J
    J --> K["~/.local/state/ssh-keys.d/"]
    K --> L["Ready for SSH auth"]
----

== Exporting Diagrams to JPEG

These Mermaid diagrams can be exported to JPEG images for full-screen viewing and presentation.

=== Option 1: Using Mermaid CLI (Recommended)

[source,bash]
----
# Install mermaid-cli (if not already installed)
npm install -g @mermaid-js/mermaid-cli

# Export all diagrams to JPEG
mmdc -i docs/ssh-keys-diagrams.adoc -o docs/diagrams/ -t dark

# Or specific formats
mmdc -i docs/ssh-keys-diagrams.adoc -o docs/diagrams/pipeline.jpeg -t dark --outputFormat jpeg
----

=== Option 2: Using Render Script

[source,bash]
----
# Make the script executable
chmod +x .github/copilot.d/bin/render-ssh-diagrams.sh

# Run the render script
.github/copilot.d/bin/render-ssh-diagrams.sh
----

=== Option 3: Using VS Code Extension

. Install "Markdown Preview Mermaid Support" extension
. Open `ssh-keys-diagrams.adoc` in VS Code
. Right-click on diagram → Export as PNG/JPEG

=== Option 4: Using Online Mermaid Editor

. Copy Mermaid code block
. Paste into https://mermaid.live/
. Export → Download JPEG
