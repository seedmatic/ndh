[NOTE]
====
Canonical runtime paths are:

* `/run/secrets/nix-darwin-home/*` (source runtime secrets)
* `/run/secrets-per-user/<user>/ssh-keys/` (private material)
* `/run/secrets-per-user/<user>/ssh-system-keys/` (public/trust material)

`/run/secrets.d` remains internal sops-nix generation storage.
====

== Sequence: home-manager switch → SSH Ready

[mermaid]
----
sequenceDiagram
    actor User
    participant hm as home-manager
    participant Nix as ssh-keys.nix
    participant Stage1 as extract-keys.sh
    participant SOPS as SOPS Decrypt
    participant Stage2 as extract-keys.sh
    participant Stage3 as ensure-authorized-keys.sh
    participant RuntimeDir as /run/secrets-per-user/&lt;user&gt;/ssh-keys/
    participant Agent as SSH Agent

    User->>hm: home-manager switch
    hm->>Nix: trigger activation
    Nix->>SOPS: decrypt nxmatic-ssh-keys.yaml
    SOPS-->>Nix: plaintext profile YAML
    Nix->>Stage1: extract keys from profile
    Stage1-->>Nix: tmp_keys_dir (keys only)
    Nix->>Stage2: extract keys to runtime dirs
    Stage2-->>Nix: runtime dirs populated
    Nix->>Stage3: ensure local authorized_keys perms
    Stage3->>RuntimeDir: runtime keys ready
    RuntimeDir-->>Stage3: ✓ deployment complete
    Stage3-->>Nix: activation complete
    Agent->>RuntimeDir: load key files
    Agent-->>User: ✓ SSH auth ready (certs auto-loaded)
----

    I --> J

== Exporting Diagrams to JPEG

These Mermaid diagrams can be exported to SVG images for scalable full-screen viewing and presentation.

=== Option 1: Using Mermaid CLI (Recommended)

[source,bash]
----
# Install mermaid-cli (if not already installed)
npm install -g @mermaid-js/mermaid-cli

# Export all diagrams to SVG
mmdc -i docs/ssh-keys-diagrams.adoc -o docs/diagrams/ -t dark --outputFormat svg

# Or use the helper script
.github/copilot.d/bin/render-ssh-diagrams.sh
----

=== Option 2: Using VS Code Extension

. Install "AsciiDoc" extension by asciidoctor
. Open `ssh-keys-diagrams.adoc` in VS Code
. Click link under diagram to open SVG (or use render script above)

=== Option 3: Using Online Mermaid Editor

. Copy Mermaid code block
. Paste into https://mermaid.live/
. Export → Download SVG
