== Technical Architecture

=== SSH Configuration Hierarchy

```
/etc/ssh/ssh_config (Darwin system-wide)
├── Base configuration (ControlMaster, ServerAlive, etc.)
├── Include ssh_config.d/*.conf
├── Include /etc/ssh/ssh_config.d/*.conf
└── Dynamic stanzas:
    ├── Profile host patterns
    ├── Guest derivations (host → host-nixos)
    ├── Local network patterns (.local)
    └── Tailnet FQDN patterns
```

=== Recursion-Safe Design Pattern

**Problem Solved:** Circular dependencies in NixOS module system
**Solution:**
- Static defaults in option definitions
- Dynamic derivations in config phase only
- Clear separation between option declarations and implementations

== Key Design Principles Applied

=== 1. Modular Architecture
- Clear separation of concerns between Darwin, Home Manager, and common modules
- Each module has a specific, well-defined responsibility
- Minimal coupling between modules

=== 2. Recursion Safety
- No config.* references in option defaults
- Static defaults with dynamic config phase resolution
- Prevents infinite recursion in NixOS module system

=== 3. Platform Agnostic Design
- Common SSH policies work across Darwin and NixOS
- Platform-specific implementations in respective module trees
- Consistent behavior across different environments

=== 4. Flexible Configuration
- Support for both explicit and derived configurations
- Override capabilities at multiple levels
- Include-based architecture for extensibility
