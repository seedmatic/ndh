== Project Context

=== Overview
This is a nix-darwin-home configuration managing:

* Darwin (macOS) system configuration
* Home Manager configurations
* Development environments
* Network infrastructure (Headscale/Tailscale replacing Teleport)
* Container orchestration (Incus + RKE2)

=== Architecture Overview

==== Network Infrastructure (Jan 2025)
* **External Access Layer**: Tailscale cloud for identity-based SSH, mobile access
* **Internal LAN Layer**: Headscale (optional) for fast local SSH (1-2ms latency)
* **Removed**: Teleport completely (Jan 9, 2025)

==== Deployment Architecture
* **rke2lab**: Kubernetes deployment (git subtree)
* **incus-headscale**: Network/VPN infrastructure (git subtree)
* **Flox environments**: Shared tooling and variables across projects

=== Key Configuration Files
* `modules/.common.d/default.nix` - Main common module configuration
* `profiles/` - System profiles (common, work, committed)
* `modules/darwin/` - Darwin-specific modules (Headscale client configured)
* `modules/home-manager/` - Home Manager configurations
* `hosts/` - Host-specific configurations (nikopol, bioskop)
* `modules/nixos/rke2lab/` - Kubernetes deployment (git subtree)
* `modules/nixos/incus-headscale/` - Network infrastructure (git subtree)

=== Working Patterns

==== Development Workflow
* **Git operations**: Done on macOS host
* **Shared directories**: `/Users/nxmatic/Gits/nxmatic/nix-darwin-home/modules/nixos/rke2lab`
* **Environment**: `flox activate -- remake NAME=headscale-server start`

==== Git Subtree Management
* Script: `.git-subtree-sync.sh`
* Commands: `pull [name]`, `push <name>`, `status [name]`
* Projects: rke2lab, incus-headscale
