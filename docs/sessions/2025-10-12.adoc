== Overview

Kickoff session to exercise the full RKE2 (incus-rke2-cluster) startup inside the Lima NixOS guest and deploy the Headscale server + gateway (incus-headscale subtree). Builds on prior guest bootstrap hardening (manual switch tooling, link-first config initialization, wait-online disable, bootloader suppression) to validate end‑to‑end network architecture (Tailscale + optional Headscale hybrid) and establish measurable health criteria.

== Objectives

* Bring up RKE2 control plane & worker(s) inside Lima VM (verify node Ready state)
* Deploy Headscale server container + gateway container (incus-headscale subtree)
* Generate Headscale user + reusable auth key; connect Darwin host + Lima guest
* Validate SSH routing & host pattern resolution (base, .local, tailnet FQDN)
* Confirm subnet routing via gateway (advertised routes visible & approved)
* Exercise container image operations (optional `ctreg` example if enabled)
* Implement a health-check script summarizing critical components
* (Optional) Implement generation diff summary before manual switch
* Update network architecture documentation & diagrams with new paths

== Health Check Script (Draft Specification)

Inputs: none (reads environment / system state)
Outputs: exit 0 if all mandatory checks pass; prints table with PASS/FAIL marks.
Checks:
* RKE2 API reachable & nodes Ready
* Headscale server health endpoint 200
* Gateway routes approved (expected list non-empty)
* SSH test (sample host pattern) returns 0
* Home Manager generation path exists & current symlink valid
* Bootloader disabled flag present (no systemd-boot units)
* Interface rename present (lima-shared, lima-bridge)

== Risks / Mitigations

| Risk | Mitigation |
|------|------------|
| Slow RKE2 provisioning | Parallelize container creation; early logs tail |
| Headscale auth delays | Pre-create reusable key; stash securely |
| Route approval missed | Add explicit checklist item in health script |
| SSH key mismatch | Use manual keychain load & confirm key presence before tests |
| Script flakiness | Allow small retry window (<=3 attempts) for network checks |
