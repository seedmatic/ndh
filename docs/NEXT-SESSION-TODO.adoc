== Alternative: Manual Deployment

If Makefile extension is complex, we can deploy manually:

=== Manual Headscale Server

[source,bash]
----
# Render cloud-config manually
cd /Users/nxmatic/Gits/nxmatic/nix-darwin-home/modules/nixos/rke2lab

export HEADSCALE_SERVER_URL="http://192.168.5.10:8080"
export HEADSCALE_BASE_DOMAIN="home.arpa"

# Render template
envsubst < cloud-config.headscale-server.yaml.tmpl > /tmp/headscale-server.yaml

# Create Incus instance
incus launch images:ubuntu/22.04 headscale-server
incus config set headscale-server cloud-init.user-data - < /tmp/headscale-server.yaml
incus restart headscale-server

# Wait and check
sleep 30
incus exec headscale-server -- systemctl status headscale
----
