== Key Concepts

=== Tailscale
Identity-based VPN using WireGuard, provides SSH with automatic key management, subnet routing via gateways.

=== Headscale
Self-hosted Tailscale control server for internal LAN, compatible with Tailscale clients, lower latency on LAN.

=== Gateways
Advertise subnet routes to make internal networks accessible via Tailscale/Headscale, deployed as Incus instances in Lima VMs.

=== Hybrid Approach
Use Tailscale for external access and mobile devices, use Headscale for fast local SSH, both provide identity-based authentication.

== Network Architecture Summary

[source]
----
External Access (Tailscale)
    ↓
Darwin Hosts (alcide, bioskop)
    ↓
Lima VMs (NixOS)
    ↓
Tailscale Gateways (Incus)
    ↓
RKE Clusters (Incus instances)

Internal LAN (Headscale - optional)
    ↓
All LAN hosts connected
    ↓
Fast local SSH
----

== Common Tasks

=== Deploy Tailscale Gateway

[source,bash]
----
# In Lima VM
limactl shell default
sudo deploy-tailscale-gateway
----

See: link:network-setup.adoc#step-1-tailscale-gateways-in-lima-vms[Tailscale Gateway Setup]

=== Setup Headscale Server

[source,nix]
----
services.headscale-custom = {
  enable = true;
  serverUrl = "http://headscale.local:8080";
  baseDomain = "home.local";
};
----

See: link:network-setup.adoc#step-3-optional-headscale-for-internal-lan[Headscale Setup]

=== Connect to Network

[source,bash]
----
# Tailscale
sudo tailscale up --ssh

# Headscale
hs-connect
----

See: link:network-setup.adoc#ssh-access[SSH Access Methods]

=== SSH to Hosts

[source,bash]
----
# Via Tailscale
tailscale ssh hostname

# Via Headscale
ssh hostname.home.local

# To RKE nodes (via gateway)
ssh 192.168.106.10
----

See: link:network-setup.adoc#usage[Usage Scenarios]

== Module Quick Reference

=== Tailscale Gateway

[source,nix]
----
services.incus-tailscale-gateway = {
  enable = true;
  authKeyFile = "/run/secrets/tailscale-authkey";
  hostname = "my-gateway";
  routes = [ "192.168.5.0/24" "192.168.106.0/24" ];
};
----

=== Headscale Server

[source,nix]
----
services.headscale-custom = {
  enable = true;
  serverUrl = "http://192.168.1.10:8080";
  baseDomain = "home.local";
};
----

=== Headscale Client

[source,nix]
----
# NixOS
services.headscale-client = {
  enable = true;
  serverUrl = "http://headscale.local:8080";
  authKeyFile = "/run/secrets/headscale-authkey";
  enableSSH = true;
};

# Darwin
services.headscale-client = {
  enable = true;
  serverUrl = "http://headscale.local:8080";
  enableSSH = true;
};
----

== Repository Structure

=== Git Subtree Integration

The `modules/nixos/incus-rke2-cluster/` directory is managed as a **git subtree**, integrating the standalone `incus-rke2-cluster` repository for RKE2 deployment.

==== Working with the Subtree

**Helper script:**
[source,bash]
----
# Pull updates from upstream
./.git-subtree-sync.sh pull

# Push changes back to upstream
./.git-subtree-sync.sh push

# Check subtree status
./.git-subtree-sync.sh status
----

**Development workflow:**

1. **RKE2-specific development** → Work in standalone `../incus-rke2-cluster/` repo
+
[source,bash]
----
cd ../incus-rke2-cluster
# Make changes, test, commit
git add .
git commit -m "Update RKE2 deployment"
git push
----

2. **Sync to nix-darwin-home**
+
[source,bash]
----
cd ../nix-darwin-home
./.git-subtree-sync.sh pull
----

3. **Integration changes** → Work in `modules/nixos/incus-rke2-cluster/`
+
[source,bash]
----
cd modules/nixos/incus-rke2-cluster
# Modify for integration needs
# Commit to nix-darwin-home
git commit -m "Integration update"
----

4. **Optional: Push improvements back**
+
[source,bash]
----
./.git-subtree-sync.sh push
----

**Manual commands:**
[source,bash]
----
# Pull from upstream
git subtree pull --prefix=modules/nixos/incus-rke2-cluster \
  ../incus-rke2-cluster main --squash

# Push to upstream
git subtree push --prefix=modules/nixos/incus-rke2-cluster \
  ../incus-rke2-cluster main
----

NOTE: Both repositories remain active. The standalone repo is ideal for focused RKE2 development, while the subtree provides integration with NixOS modules.
