== Architecture Design

=== Network Topology

```
bioskop (Mac Mini M4 Pro - Stationary)
├── Darwin Host
│   └── Headscale Client → connects to 192.168.5.10:8080
│
└── Lima VM (NixOS) - nerd-nixos
    ├── Incus: headscale-server
    │   ├── IP: 192.168.5.10
    │   ├── Ports: 8080 (HTTP), 50443 (gRPC)
    │   └── Network: 100.64.0.0/10 (Headscale mesh)
    │
    ├── Incus: headscale-gateway
    │   ├── Connects to: Tailscale network (100.x.x.x)
    │   ├── Advertises to Tailscale:
    │   │   - 100.64.0.0/10 (Headscale network)
    │   │   - 192.168.1.0/24 (Home LAN)
    │   │   - 192.168.5.0/24 (Lima network)
    │   │   - 10.80.16.0/20 (bioskop RKE2 cluster)
    │   └── Bridges: Tailscale ↔ Headscale
    │
    └── Incus: RKE2 Cluster (via incus-rke2-cluster)
        ├── Network: 10.80.16.0/20 (bioskop)
        ├── Pods: 10.42.0.0/16
        ├── Services: 10.43.0.0/16
        ├── K8s API VIP: 10.80.16.250/32
        ├── LoadBalancer pool: 10.80.16.128/26
        └── Tailscale Operator (exposes K8s services)

alcide (MacBook Pro - Mobile)
└── Tailscale Client ONLY
    ↓
    Connects via Tailscale to everything
```

=== Access Patterns

**alcide (mobile) → bioskop infrastructure:**
```
alcide (anywhere)
    ↓ Tailscale (100.x.x.x)
headscale-gateway (in bioskop Lima VM)
    ↓ Bridge
Headscale network (100.64.0.0/10)
    ↓
bioskop Darwin / Lima VM / RKE2
```

**bioskop → Lima VM (local):**
```
bioskop Darwin
    ↓ Headscale (100.64.x.x) or Direct (192.168.5.x)
Lima VM nerd-nixos
```
