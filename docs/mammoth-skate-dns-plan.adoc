= mammoth-skate.fr.eu.org - Authoritative DNS: Implementation Plan
:toc: left
:toclevels: 3
:icons: font

== Plan header

*Goal:* Deploy an authoritative Knot DNS server for `mammoth-skate.fr.eu.org` on
the NixOS guest `nixos.bioskop`, exposed on the public Internet via Bbox port
forward, with a free secondary on afraid.org, then register the delegation at
nic.eu.org.

*Architecture:* A new NixOS module `modules/nixos/dns-authoritative.nix`
configures Knot DNS (zone + SOA + NS + A/AAAA) and opens firewall port 53
(UDP+TCP). Activated in `hosts/bioskop/nixos.nix`. Port-forward and DNS
secondary setup are manual ops steps.

*Tech stack:* NixOS, Knot DNS (`services.knot`), afraid.org (FreeDNS secondary).

*Spec:* `docs/mammoth-skate-dns-spec.adoc`

== Global constraints

* Domain: `mammoth-skate.fr.eu.org`.
* NS1: `mammoth-skate.duckdns.org` (no glue record needed).
* NS2: afraid.org secondary (to be created).
* Knot listens on `0.0.0.0:53`.
* Firewall: UDP 53 and TCP 53 open.
* No DNSSEC in v1.

== Review focus

* The zone must respond authoritatively (SOA + NS) before nic.eu.org submission.
* Port 53 must be reachable from the public Internet (both UDP and TCP).
* The secondary must successfully AXFR the zone from the primary.
* The VM bridged IP must be stable (DHCP reservation on Bbox recommended).
